## Socioprophet/Containers

This is the portion of the SocioProphet repo that contains the code / specifications for building the containers used by the platform. The codebase and repo is a work in progress.

## Scioprophet/Containers top-level directory layout

```bash
    .
    .gitignore                      
    ├── Makefile                    
    ├── aiml                 # Prophet-platform code for developing and sharing AIML assets
    │   └──**/**                    
    ├── data-io              # Prophet-platform code for add data & io related containers
    │   └──**/**                   
    ├── dev-user             # Prophet-platform code for {user} home, terminal, and ide integration
    │   └──**/**                  
    ├── knowledge-management # Prophet-platform code for knowledge management and knowledge engineering
    │   └──**/**          
    ├── prophet-platform     # Prophet-platform code for sharing data, storage & compute
    │   └──**/**                                
    └──socioprophet-web      # Directory containing website platform code (back-end and front-end)
        └──**/** 
```
