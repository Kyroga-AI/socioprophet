---
name: SocioProphet deck mirrors marketing site
description: The slide deck's visual language is deliberately slaved to the marketing website's brand, not an independent design.
---

The `socioprophet-deck` artifact intentionally mirrors the `socioprophet`
marketing website's design language: dark near-black ground, near-white text,
muted-teal (#3FB6C2) for section/category labels, violet (#866CF7) for hero
eyebrows / email CTA / pull-quote left-bars, and Plus Jakarta Sans + Space Mono.

**Why:** the user asked for the deck to carry the website's "complementary
messaging and design" so the two artifacts read as one brand. The deck was
originally a light investor-memo; it was converted to match the site.

**How to apply:** when restyling either artifact, keep them in sync — pull
palette/typography cues from `artifacts/socioprophet/src/index.css` and the
site's hero/section copy. Don't reintroduce the old light investor-memo palette
in the deck.
